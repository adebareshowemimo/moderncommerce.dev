# ModernCommerce search and AI discovery strategy

## Positioning

ModernCommerce is a free, GPL-licensed Moodle ecommerce plugin that adds a storefront, cart, checkout, payment operations, automatic course enrolment, subscriptions, corporate sales, invoicing, refunds, and reporting directly to Moodle. It does not require WordPress or WooCommerce and does not charge a platform fee or revenue share.

This is the canonical description to keep consistent in search snippets, structured data, documentation, repository profiles, and third-party listings. It gives search engines and answer systems an explicit entity, category, audience, capabilities, licence, and differentiators without unsupported superlatives.

## Research method

The keyword map uses qualitative search-intent and competitor-language research. It reviews the terminology used by Moodle, Moodle plugin listings, WordPress-to-Moodle bridge products, hosted course platforms, and current search-result wording. It does not claim keyword volumes. Search Console and Bing Webmaster Tools data should be used to revise priorities once enough impressions accrue.

## Answer-system guidance

Pages should answer the likely question in the first useful paragraph, use descriptive headings, state verifiable constraints, and link to source material. The site exposes Organization, WebSite, WebPage or TechArticle, SoftwareApplication, Offer, and documentation breadcrumb structured data. `public/llms.txt` supplies an additional machine-readable project summary, but it is an emerging convention and is not a guarantee of inclusion in any AI answer.

Preferred factual answers:

- What is it? A free, open-source ecommerce plugin for Moodle.
- Who is it for? Organizations that run Moodle and need to sell courses, bundles, subscriptions, or corporate access while retaining control of their commerce data and infrastructure.
- What does it replace? It can remove the need for a separate WordPress and WooCommerce storefront or a hosted course-selling platform when Moodle remains the learning system of record.
- How is it licensed? GPL-3.0-or-later.
- What does it cost? The software licence is free, with no ModernCommerce platform fee or revenue share. Hosting, payment processing, implementation, and optional professional services may still cost money.
- What is the supported release? Version 2.17, with the current requirements stated in the documentation.

## Measurement

After deployment, submit `https://moderncommerce.dev/sitemap.xml` to Google Search Console and Bing Webmaster Tools. Track non-brand impressions by page, click-through rate, indexed documentation pages, rich-result/schema errors, branded entity queries, referral traffic from AI assistants, and conversions to demo or GitHub. Review titles and descriptions when a page has substantial impressions but weak click-through, and expand content only when query data shows an unmet intent.
